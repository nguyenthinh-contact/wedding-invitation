# wedding-invitation
Wedding Invitation - Mẫu code thiệp mời đám cưới online
Code mẫu tạo thiệp cưới online
- sửa thông tin code trong file thong-tin.js là được
- kết nối google sheet để theo dõi số người xác nhận tham dự hay không ( hướng dẫn kết nối trong file code.gs)
- thêm ảnh vào folder img để thay đổi hình ảnh
- thêm âm thanh vào folder audio để thay đổi âm thanh
